# ✏️ Nano — Quick Editing 

Nano is a simple terminal text editor.
## Open a File

```bash
# examples
nano filename.py
nano exploit.sh
nano config.txt
```

| **Action** | **Command**      |
| ---------- | ---------------- |
| Save file  | CTRL + O → Enter |
| Exit nano  | CTRL + X         |
| Cut line   | CTRL + K         |
| Paste line | CTRL + U         |
| Search     | CTRL + W         |
| Go to line | CTRL + _         |
| Undo       | ALT + U          |
| Redo       | ALT + E          |
